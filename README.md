## 📌 Deskripsi

Landing page portofolio interaktif ini dirancang khusus untuk memamerkan identitas **smailk** serta produk unggulan **SMAILK Lifestyle Sneakers**. Website ini mengusung tema *GitHub Dark Mode* yang elegan, responsif, dan ringan.

 visual produk interaktif mendukung switching tampilan **6 Varian Warna**:
1. 🐼 **Panda** *(Black & White - Warna Utama)*
2. ⚪ **Triple White** *(Clean Look)*
3. 🐘 **Neutral Grey** *(Grey & White)*
4. 🌾 **Oatmeal** *(Beige / Cream)*
5. 🔵 **Classic Navy** *(Navy Blue & White)*
6. 🖤 **Triple Black** *(Stealth)*

---

## 💡 Fitur Utama

- **Interactive Color Swatches**: Mengubah preview varian warna secara *real-time* via JavaScript.
- **Dynamic JSON Data**: Seluruh data produk & keunggulan tersimpan rapi di `products.json`.
- **Responsive Layout**: Tampilan optimal di perangkat Desktop, Tablet, maupun HP.
- **Modern Icons**: Menggunakan set ikon dari [Lucide Icons](https://lucide.dev/).

---

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Struktur halaman semantik.
- **CSS3**: Layouting (Flexbox & CSS Grid), CSS Custom Variables, dan Github Dark Mode styling.
- **JavaScript (ES6+)**: Logika pemrosesan data JSON dan interaktivitas DOM.
- **JSON**: Media penyimpanan data produk modern.
